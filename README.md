# APL Logistics Analytics

**Project:** Customer, Product, and Profitability Performance Analysis in Supply Chain Operations  
**Program:** Unified Mentor  
**Tools:** Python, Pandas, Plotly, Streamlit

## Project objectives

This project moves beyond revenue-only reporting to examine profitability by customer, product, category, market and region. It also explores the relationship between discounts and profit, and includes a clearly labelled simplified what-if discount scenario.

## Dashboard modules

1. **Revenue & Profit Overview** — total revenue, total recorded profit, profit margin and order-status comparison.
2. **Customer Value Dashboard** — top/bottom customers by profit, customer segment contribution and customer profitability tiers.
3. **Product & Category Performance** — product and category profit, margin heatmap, high-revenue/low-margin screening and loss-making categories.
4. **Discount Impact Analyzer** — discount rate versus profit ratio, discount bands and a what-if discount sensitivity calculator.
5. **Market, Regional Profit & Data Quality** — market, region, country profitability and data-quality checks.

## Dataset

Place the supplied dataset at `data/APL_Logistics.csv`. The included CSV is the file supplied for this project.

The data contains order-item, customer, product, discount, shipping, market and region fields. The supplied file does **not** contain an order-date field; therefore the app does not fabricate a time-series trend.

## Setup in VS Code (Windows)

1. Install Python 3.10 or newer.
2. Open this folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Create a virtual environment:

   ```powershell
   python -m venv .venv
   ```

5. Activate it in PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt terminal or run the commands without activating and use `.venv\Scripts\python.exe -m pip ...`.

6. Install libraries:

   ```powershell
   python -m pip install -r requirements.txt
   ```

7. Start the dashboard:

   ```powershell
   streamlit run app.py
   ```

8. Streamlit will display a local URL, normally `http://localhost:8501`.

## Generate analysis CSVs

```powershell
python analysis.py
```

Generated files include overall summary, customer, product, category, market, region and country profitability tables.

## Financial definitions and assumptions

- **Revenue:** sum of `Sales` for included rows.
- **Profit:** sum of `Order Profit Per Order`, as supplied in the dataset.
- **Profit margin:** total profit divided by total sales × 100.
- **Customer value:** aggregate recorded profit by `Order Customer Id`.
- **Discount rate:** `Order Item Discount Rate` multiplied by 100 for display.
- Negative-profit rows are retained because they may be genuine business losses.
- Rows with missing core financial values or non-positive sales are excluded from the main financial analysis and counted in the data-quality view.
- The what-if discount calculator is a simplified sensitivity scenario: the additional discount is assumed to reduce revenue and profit dollar-for-dollar while volume and costs stay constant. It is not a causal forecast.
- Currency is not explicitly stated in the dataset. The dashboard uses `$` as a display convention; verify currency before external publication.

## Data quality and privacy

The app uses a fallback Latin-1 encoding if UTF-8 reading fails. It checks missing financial values and duplicate rows. It does not automatically delete all duplicates or negative-profit records. The source data contains customer names and street addresses; remove or mask identifying fields before publishing public screenshots or reports.
